# ५. জিওআইপি এবং ভৌগোলিক ট্র্যাকিং

## 🎯 এই বৈশিষ্ট্যটি কি?

প্যাকেজটি প্রতিটি অনুরোধকারীর আইপি ঠিকানা থেকে তাদের দেশ এবং শহর সনাক্ত করে।

## 🤔 কেন প্রয়োজন?

- আপনার ব্যবহারকারী কোথা থেকে আসছে জানুন
- নির্দিষ্ট দেশ থেকে ট্রাফিক ট্র্যাক করুন
- সন্দেহজনক অবস্থান থেকে প্রবেশ সনাক্ত করুন
- সার্ভার অবস্থান অপ্টিমাইজ করুন
- লোকেলাইজেশন উন্নত করুন

## 📍 কি তথ্য ক্যাপচার করা হয়?

প্রতিটি রিকোয়েস্টের জন্য:

| ডেটা | বর্ণনা | উদাহরণ |
|------|-------|---------|
| **আইপি ঠিকানা** | ক্লায়েন্ট IP | 192.168.1.1 |
| **দেশ** | দেশের নাম | Bangladesh |
| **দেশ কোড** | ISO কোড | BD |
| **শহর** | শহরের নাম | Dhaka |
| **অঞ্চল** | অঞ্চল/প্রাদেশিক | Dhaka Division |
| **অক্ষাংশ** | ভৌগলিক অক্ষাংশ | 23.8103 |
| **দ্রাঘিমাংশ** | ভৌগলিক দ্রাঘিমাংশ | 90.4129 |
| **টাইমজোন** | স্থানীয় সময়ঞ্চল | Asia/Dhaka |

## 🔧 কনফিগারেশন

### জিওআইপি ট্র্যাকিং চালু/বন্ধ

```php
// config/request-log-analyzer.php
'track_geo' => env('REQUEST_LOG_ANALYZER_TRACK_GEO', true),
```

`.env` ফাইলে:

```env
REQUEST_LOG_ANALYZER_TRACK_GEO=true
```

### জিওআইপি API কনফিগার করুন

```php
'geo_api_url' => env('REQUEST_LOG_ANALYZER_GEO_API_URL', 'http://ip-api.com/json/{ip}'),
'geo_timeout_seconds' => (int) env('REQUEST_LOG_ANALYZER_GEO_TIMEOUT', 2),
```

**ডিফল্ট API**: `ip-api.com`
- বিনামূল্যে ব্যবহার: প্রতি মাসে ৪৫,০০০ অনুরোধ
- দ্রুত প্রতিক্রিয়া: সাধারণত < ১০০ms

### কাস্টম জিওআইপি API ব্যবহার করুন

যদি আপনার নিজস্ব জিওআইপি সেবা থাকে:

```php
'geo_api_url' => env(
    'REQUEST_LOG_ANALYZER_GEO_API_URL',
    'https://your-geo-api.com/json/{ip}'
),
```

**.env** এ:

```env
REQUEST_LOG_ANALYZER_GEO_API_URL=https://your-geo-api.com/json/{ip}
REQUEST_LOG_ANALYZER_GEO_TIMEOUT=5
```

## 📊 ভৌগোলিক ডেটা দেখুন

### বিশ্ব মানচিত্র

প্রধান ড্যাশবোর্ডে:

```
/request-log-analyzer
```

"দেশ অনুযায়ী অনুরোধ" বিভাগ দেখুন:

- **মানচিত্র** - সমস্ত ট্রাফিক একটি মানচিত্রে
- **শীর্ষ দেশ** - সবচেয়ে বেশি অনুরোধ আসে এমন দেশ
- **সংখ্যা** - প্রতিটি দেশ থেকে কত অনুরোধ

### দেশ-ভিত্তিক ফিল্টার

নির্দিষ্ট দেশ থেকে অনুরোধ দেখুন:

```
/request-log-analyzer/requests?country=BD
```

যেখানে `BD` = বাংলাদেশ

### শহর-স্তরের বিশ্লেষণ

```
/request-log-analyzer/requests?city=Dhaka
```

## 🗺️ উন্নত বিশ্লেষণ

### ট্রাফিক গরম মানচিত্র

সবচেয়ে সক্রিয় অঞ্চল দেখুন:

```
/request-log-analyzer/analytics?view=geo-heatmap
```

রঙ শক্তিশালী = আরও ট্রাফিক

### টাইমজোন বিশ্লেষণ

বিভিন্ন সময়ে ব্যবহারকারী সক্রিয়?

```
/request-log-analyzer/analytics?view=timezone
```

দেখবেন:
- কোন টাইমজোন সক্রিয়
- পিক সময় সেখানে কখন
- নিম্ন সময় কখন

## 🔐 গোপনীয়তা বিবেচনা

### আইপি লুকান/দেখান

আইপি ঠিকানা প্রদর্শন করবেন কি?

```php
// config/request-log-analyzer.php
'hide_ip_addresses' => env('REQUEST_LOG_ANALYZER_HIDE_IPS', false),
```

এটি `true` হলে শুধু দেশ দেখা যাবে, আইপি লুকিয়ে থাকবে।

### GDPR সম্মতি

ইউরোপীয় ব্যবহারকারীদের জন্য জিওআইপি ডেটা সংগ্রহে বিধিনিষেধ থাকতে পারে।

```php
'respect_gdpr' => env('REQUEST_LOG_ANALYZER_RESPECT_GDPR', true),
```

এটি সক্ষম হলে EU ব্যবহারকারীদের জিওআইপি ডেটা সংগ্রহ করবে না।

## 🛡️ সন্দেহজনক অবস্থান সনাক্তকরণ

### অসম্ভব ভ্রমণ সনাক্ত করুন

একজন ব্যবহারকারী ২ ঘণ্টায় দুটি মহাদেশ থেকে অনুরোধ করছে?

**স্বয়ংক্রিয় সতর্কতা** (যদি সক্ষম):

```php
'detect_impossible_travel' => true,
```

### নতুন অবস্থান সতর্কতা

ব্যবহারকারী যদি নতুন দেশ থেকে লগইন করে:

```php
'alert_new_country' => true,
'alert_email' => 'security@example.com',
```

ইমেইল পাবেন নতুন অবস্থান সম্পর্কে।

## 📈 ভৌগলিক রিপোর্ট

### ট্রাফিক বিতরণ

```
/request-log-analyzer/analytics?view=geo-distribution
```

দেখবেন:
- শীর্ষ ১০ দেশ
- শীর্ষ ২০ শহর
- সবচেয়ে সক্রিয় অঞ্চল

### সময় অনুযায়ী ট্রাফিক

কোন সময়ে কোন জায়গা থেকে সবচেয়ে বেশি ট্রাফিক:

```
/request-log-analyzer/analytics?view=geo-timeline
```

এটি দেখায় যখন প্রতিটি দেশ সবচেয়ে সক্রিয়।

## 💾 ডাটাবেস

ভৌগলিক ডেটা এখানে সংরক্ষিত:

```
rla_requests (geo_country, geo_city, geo_latitude, geo_longitude কলাম)
```
