# ९. ড্যাশবোর্ড সম্পূর্ণ ব্যবহার গাইড

## 🎯 ড্যাশবোর্ড কি?

ড্যাশবোর্ড একটি ইন্টারেক্টিভ ওয়েব ইন্টারফেস যেখানে আপনার অ্যাপ্লিকেশনের সমস্ত কার্যকলাপ দেখতে পারেন।

## 🌍 ড্যাশবোর্ড অ্যাক্সেস করুন

```
http://your-app.test/request-log-analyzer
```

**লগইন করুন** (যদি প্রয়োজন):
- ড্যাশবোর্ড `web` মিডলওয়্যার ব্যবহার করে
- লগইন প্রয়োজন অনুযায়ী কনফিগার করুন

## 📑 ড্যাশবোর্ড পৃষ্ঠাগুলি

### १. প্রধান পৃষ্ঠা (Overview)

```
/request-log-analyzer
```

**শীর্ষে চার কার্ড**:

| কার্ড | অর্থ | ব্যবহার |
|-------|------|--------|
| **আজকের রিকোয়েস্ট** | আজ কত অনুরোধ | ট্রাফিক ট্রেন্ড দেখুন |
| **এখনই সক্রিয়** | বর্তমান অনলাইন ব্যবহারকারী | ব্যবহারকারী কার্যকলাপ দেখুন |
| **শীর্ষ রুট** | সবচেয়ে জনপ্রিয় URI | গুরুত্বপূর্ণ রুট চিহ্নিত করুন |
| **মোট ব্যবহারকারী** | কখনো দেখা স্বতন্ত্র ব্যবহারকারী | ব্যবহারকারী বেস আকার |

**মূল চার্টস**:
- ঘণ্টায় অনুরোধ প্রবণতা
- ঘণ্টায় ত্রুটি প্রবণতা
- দেশ অনুযায়ী ট্রাফিক মানচিত্র

**সম্পর্কিত তালিকা**:
- সর্বশেষ ত্রুটি (শীর্ষ ৫)
- সবচেয়ে ধীর কোয়েরি (শীর্ষ ৫)
- সবচেয়ে দ্রুত বর্ধনশীল রুট (শীর্ষ ৫)

### २. অনুরোধ তালিকা (Requests)

```
/request-log-analyzer/requests
```

**কলাম প্রদর্শনী**:
- ⏱️ সময় - অনুরোধের সময়
- 📝 মেথড - GET, POST, PUT, DELETE
- 🔗 URI - অনুরোধের পাথ
- 🔢 কোড - স্ট্যাটাস কোড (২०० = সবুজ, ४०४ = কমলা, ५००= লাল)
- ⚡ সময় - মিলিসেকেন্ডে সময়কাল
- 👤 ব্যবহারকারী - কে অনুরোধ করেছে

**ফিল্টার**:
```
?method=POST&status=5xx&uri=/api/users&tag=payment
```

### ३. রিকোয়েস্ট বিস্তারিত

যেকোনো রিকোয়েস্টে ক্লিক করুন:

```
/request-log-analyzer/requests/123
```

**ট্যাব**:

**অনুরোধ (Request)**:
- মেথড এবং URL
- প্রত্যাশিত এবং প্রতিক্রিয়া হেডার
- ফর্ম ডেটা এবং কোয়েরি পরামিতি
- কুকি

**প্রতিক্রিয়া (Response)**:
- স্ট্যাটাস কোড এবং বার্তা
- প্রতিক্রিয়া হেডার
- প্রতিক্রিয়া বডি (JSON সুন্দরভাবে মুদ্রিত)

**কোয়েরি (Queries)**:
- সব SQL কোয়েরি
- প্রতিটি কোয়েরির সময়
- কোয়েরি বাইন্ডিং (প্যারামিটার)
- কোথা থেকে কোয়েরি করা হয়েছে (ফাইল/লাইন)

**ত্রুটি (Errors)**:
- যেকোনো ব্যতিক্রম
- সম্পূর্ণ স্ট্যাক ট্রেস
- ত্রুটি প্রসঙ্গ

**সময়ভিত্তিক (Timeline)**:
- জীবনচক্র ধাপ (middleware, routing, action, response)
- প্রতিটি ধাপের সময়
- ওয়াটারফল ভিউ

### ४. অ্যানালিটিক্স

```
/request-log-analyzer/analytics
```

**টাইম সিলেক্টর**:
- আজ
- গত २४ ঘণ্টা
- গত ७ দিন
- গত ३० দিন

**মেট্রিক্স**:

| মেট্রিক | অর্থ |
|--------|------|
| মোট অনুরোধ | সময়ের মধ্যে কত অনুরোধ |
| গড় সময় | গড় প্রতিক্রিয়া সময় |
| সর্বোচ্চ সময় | সবচেয়ে ধীর অনুরোধ |
| ত্রুটি | কত অনুরোধ ব্যর্থ হয়েছে |
| ত্রুটি হার | মোট অনুরোধের % ত্রুটি |

**তালিকা**:
- সবচেয়ে ধীর রুট (শীর্ষ १५)
- সবচেয়ে জনপ্রিয় রুট (শীর্ষ १५)
- সবচেয়ে ঘন ঘন ত্রুটি (শীর্ষ १०)

### ५. সক্রিয় ব্যবহারকারী

```
/request-log-analyzer/active-users
```

**রিয়েল-টাইম তথ্য**:
- এখনই কতজন অনলাইন
- প্রতিটি ব্যবহারকারীর নাম
- তাদের শেষ কার্যকলাপ (কতক্ষণ আগে)
- তারা কোথা থেকে অ্যাক্সেস করছে (দেশ)

### ६. ব্যবহারকারী রুট হিট

```
/request-log-analyzer/user-route-hits
```

**প্রতিটি ব্যবহারকারীর জন্য**:
- কোন রুট ব্যবহার করছেন
- প্রতিটি রুটে কত বার
- সর্বশেষ ব্যবহার করা সময়

**ফিল্টার**:
- নাম দ্বারা ব্যবহারকারী খুঁজুন
- রুট দ্বারা ফিল্টার করুন

### ७. লগইন ইতিহাস

```
/request-log-analyzer/login-history
```

**প্রতিটি লগইন প্রদর্শনী**:
- ব্যবহারকারী ইমেইল
- লগইন সময়
- লগআউট সময় (যদি আছে)
- আইপি ঠিকানা এবং দেশ
- ডিভাইস/ব্রাউজার

**সনাক্তকরণ**:
- নতুন ডিভাইস = লাল সতর্ক চিহ্ন 🚩
- নতুন অবস্থান = কমলা সতর্ক চিহ্ন ⚠️
