# ६. লগইন ইতিহাস এবং সক্রিয় ব্যবহারকারী

## 🎯 এই বৈশিষ্ট্যটি কি?

প্যাকেজটি প্রতিটি লগইন এবং লগআউট ইভেন্ট রেকর্ড করে এবং কে এখনই অনলাইন তা ট্র্যাক করে।

## 🤔 কেন প্রয়োজন?

- কে এবং কখন লগইন করছে তা জানুন
- অসামান্য লগইন কার্যকলাপ সনাক্ত করুন
- এখনই কত ব্যবহারকারী অনলাইন
- একটি ব্যবহারকারীর লগইন প্যাটার্ন দেখুন
- নিরাপত্তা সমস্যা সনাক্ত করুন

## 📝 কি তথ্য সংরক্ষিত হয়?

### লগইন ইভেন্ট

প্রতিটি লগইনে:

| তথ্য | বর্ণনা | উদাহরণ |
|------|-------|---------|
| **ব্যবহারকারী** | লগইন করা ব্যবহারকারী | john@example.com |
| **ইমেইল** | ব্যবহারকারীর ইমেইল | john@example.com |
| **সময়** | কখন লগইন করেছে | ২০२६-०५-१३ १४:३२ |
| **আইপি** | লগইন করার আইপি | 192.168.1.1 |
| **দেশ** | লগইন অবস্থান | Bangladesh |
| **ডিভাইস** | ব্রাউজার/ডিভাইস | Chrome on Windows |
| **প্রকার** | লগইন বা লগআউট | login, logout |

### সক্রিয় ব্যবহারকারী

এখনই কারা অনলাইন:

| তথ্য | অর্থ |
|------|------|
| **সংখ্যা** | এখনই অনলাইন ব্যবহারকারী |
| **সময় উইন্ডো** | কত সময়ে বিবেচনা করা হয় |
| **শেষ সক্রিয়** | প্রতিটি ব্যবহারকারীর শেষ কার্যকলাপ |

## 🔧 কনফিগারেশন

### লগইন ট্র্যাকিং চালু/বন্ধ

```php
// config/request-log-analyzer.php
'track_login_history' => env('REQUEST_LOG_ANALYZER_TRACK_LOGIN_HISTORY', true),
```

`.env` ফাইলে:

```env
REQUEST_LOG_ANALYZER_TRACK_LOGIN_HISTORY=true
```

### সক্রিয় ব্যবহারকারী সময় উইন্ডো

কত সময় আগে "সক্রিয়" বলবেন?

```php
'active_users_window_minutes' => (int) env(
    'REQUEST_LOG_ANALYZER_ACTIVE_WINDOW_MINUTES',
    5
),
```

**ডিফল্ট**: ৫ মিনিট
- একজন ব্যবহারকারী গত ৫ মিনিটে কার্যকলাপ করেছে = সক্রিয়

`.env` এ পরিবর্তন করুন:

```env
REQUEST_LOG_ANALYZER_ACTIVE_WINDOW_MINUTES=10  # ১০ মিনিট
REQUEST_LOG_ANALYZER_ACTIVE_WINDOW_MINUTES=30  # ৩০ মিনিট (দীর্ঘ)
```

## 📊 লগইন ইতিহাস দেখুন

### সমস্ত লগইন/লগআউট

```
/request-log-analyzer/login-history
```

এখানে পাবেন:
- সমস্ত লগইন ইভেন্ট
- সর্বশেষ প্রথমে দেখানো
- ফিল্টার করার অপশন

### লগইন রেকর্ড ফিল্টার করুন

নির্দিষ্ট ব্যবহারকারী খুঁজুন:

```
/request-log-analyzer/login-history?user=john@example.com
```

নির্দিষ্ট তারিখ:

```
/request-log-analyzer/login-history?date=2026-05-13
```

শুধু লগআউট:

```
/request-log-analyzer/login-history?type=logout
```

### একটি ব্যবহারকারীর সম্পূর্ণ ইতিহাস

কোনো রিকোয়েস্টে ব্যবহারকারীর নাম ক্লিক করলে তার সম্পূর্ণ ইতিহাস দেখা যাবে:

```
/request-log-analyzer/login-history?user_id=42
```

দেখবেন:
- সমস্ত লগইন তারিখ
- সব আইপি এবং অবস্থান
- প্যাটার্ন এবং অসংগতি

## 👥 সক্রিয় ব্যবহারকারী দেখুন

### এখনই অনলাইন ব্যবহারকারী

```
/request-log-analyzer/active-users
```

দেখবেন:
- এখনই কত মানুষ অনলাইন
- প্রতিটি ব্যবহারকারীর নাম
- তাদের শেষ কার্যকলাপ
- তারা কোথা থেকে অ্যাক্সেস করছে

### লাইভ গণনা

প্রধান ড্যাশবোর্ডে তাৎক্ষণিক সংখ্যা:

```
/request-log-analyzer
```

"এখনই সক্রিয় ব্যবহারকারী" কার্ড দেখুন।

## 🔍 নিরাপত্তা বিশ্লেষণ

### অসাধারণ লগইন সনাক্ত করুন

**অভিযোগ**: একটি অ্যাকাউন্ট দুটি দেশ থেকে ১ ঘণ্টায় অ্যাক্সেস হয়েছে?

**সনাক্তকরণ**:

```
/request-log-analyzer/login-history?user=john@example.com
```

শেষ ১০টি এন্ট্রি দেখুন - ভৌগলিক এবং সময়গত সংঘর্ষ দেখুন।

### নতুন ডিভাইস থেকে লগইন

একজন ব্যবহারকারী নতুন ডিভাইস থেকে লগইন করছে?

লগইন ইতিহাসে দেখবেন:

```
Firefox on Windows ← লাল (নতুন ডিভাইস)
Chrome on Windows   ← সাধারণ
Chrome on iPhone    ← লাল (নতুন ডিভাইস)
```

### সন্দেহজনক প্যাটার্ন

স্বয়ংক্রিয় সতর্কতা সেট করুন:

```php
// config/request-log-analyzer.php
'suspicious_login_alert' => true,
'alert_new_ip_country' => true,
'alert_new_device' => true,
```

## 📈 লগইন পরিসংখ্যান

### ব্যবহারকারী রুট হিট

প্রতিটি ব্যবহারকারী কোন রুট ব্যবহার করছে:

```
/request-log-analyzer/user-route-hits
```

দেখবেন:
- ব্যবহারকারী নাম
- প্রতিটি রুটে ব্যবহার সংখ্যা
- কখন শেষে ব্যবহার করেছে

### সক্রিয় ব্যবহারকারী প্রবণতা

সময়ের সাথে ব্যবহারকারী কার্যকলাপ:

```
/request-log-analyzer/analytics?view=active-users-timeline
```

দেখবেন:
- প্রতি ঘণ্টায় সক্রিয় ব্যবহারকারীর গ্রাফ
- পিক সময়
- কম সময়

## 🔐 সংবেদনশীল লগইন ডেটা

### সংবেদনশীল লগইন উপেক্ষা করুন

নির্দিষ্ট লগইন টাইপ লগ করবেন না:

```php
'ignore_login_for_roles' => [
    'admin_impersonation',  // Admin যখন ব্যবহারকারীর ভান করে
    'test_user',            // পরীক্ষা অ্যাকাউন্ট
],
```

### পাসওয়ার্ড লুকান

লগইন ফর্মের পাসওয়ার্ড লুকিয়ে দিন:

```php
'hide_login_passwords' => true,
```

## 💾 ডাটাবেস টেবিল

লগইন ডেটা এখানে সংরক্ষিত:

```
rla_user_login_histories
rla_active_users
```

## ✅ সেরা অনুশীলন

१. **নিয়মিত পর্যবেক্ষণ** - অস্বাভাবিক লগইন প্যাটার্ন খুঁজুন

२. **সতর্কতা সেট করুন** - নতুন ডিভাইস বা অবস্থানের জন্য

३. **সময়োপযোগী কাজ করুন** - সন্দেহজনক কার্যকলাপ দেখলে তাৎক্ষণিক ব্যবস্থা নিন

४. **পরিচয় যাচাইকরণ** - অসাধারণ লগইনের জন্য ব্যবহারকারীকে যাচাই করুন
