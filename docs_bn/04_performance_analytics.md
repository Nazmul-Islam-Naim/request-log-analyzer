# ४. পারফরম্যান্স বিশ্লেষণ এবং অ্যানালিটিক্স

## 🎯 এই বৈশিষ্ট্যটি কি?

প্যাকেজটি সমস্ত রিকোয়েস্ট এবং রুটের পারফরম্যান্স মেট্রিক্স বিশ্লেষণ করে এবং অন্তর্দৃষ্টি প্রদান করে।

## 🤔 কেন প্রয়োজন?

- কোন রুট সবচেয়ে ধীর?
- গড় প্রতিক্রিয়া সময় কত?
- পিক সময়ে কতটা লোড আছে?
- কোন রুট সবচেয়ে বেশি ব্যবহৃত?
- পারফরম্যান্স অপ্টিমাইজেশনে অগ্রাধিকার কী?

## 📊 অ্যানালিটিক্স দেখুন

### প্রধান অ্যানালিটিক্স পৃষ্ঠা

```
/request-log-analyzer/analytics
```

এখানে পাবেন:

| মেট্রিক | বর্ণনা |
|--------|-------|
| **মোট রিকোয়েস্ট** | আজ কত রিকোয়েস্ট |
| **গড় সময়** | রিকোয়েস্টের গড় সময়কাল |
| **সর্বোচ্চ সময়** | সবচেয়ে ধীর রিকোয়েস্ট |
| **ত্রুটি হার** | প্রতিটি রিকোয়েস্টে ত্রুটির শতাংশ |
| **সবচেয়ে ধীর রুট** | শীর্ষ ৫ ধীর রুট |
| **সবচেয়ে জনপ্রিয় রুট** | শীর্ষ ৫ সর্বাধিক ব্যবহৃত রুট |

### রুট-ভিত্তিক অ্যানালিটিক্স

প্রতিটি রুট সম্পর্কে বিস্তারিত:

| তথ্য | মানে |
|------|------|
| **হিট সংখ্যা** | এই রুটে কত রিকোয়েস্ট |
| **গড় সময়** | এই রুটের গড় সময় |
| **সর্বোচ্চ সময়** | এই রুটের সর্বোচ্চ সময় |
| **ত্রুটি সংখ্যা** | এই রুটে কত ত্রুটি |

## 📈 চার্ট এবং গ্রাফ

### রিয়েল-টাইম ড্যাশবোর্ড

প্রধান পৃষ্ঠায় লাইভ চার্ট:

**স্বয়ংক্রিয় আপডেট** - ডেটা স্বয়ংক্রিয়ভাবে রিফ্রেশ হয়

এখানে দেখবেন:
- প্রতি ঘণ্টায় রিকোয়েস্ট প্রবণতা
- প্রতি ঘণ্টায় ত্রুটির প্রবণতা
- ধীম রিকোয়েস্টের প্রবণতা

### ভৌগলিক বিতরণ

কোথা থেকে ট্রাফিক আসছে:

```
/request-log-analyzer
```

"দেশ অনুযায়ী অনুরোধ" চার্ট দেখুন।

## 🔧 কনফিগারেশন

### ধীম রিকোয়েস্ট থ্রেশহোল্ড

কি সময়কে "ধীম" বলবেন?

```php
// config/request-log-analyzer.php
'slow_request_threshold_ms' => env('REQUEST_LOG_ANALYZER_SLOW_MS', 500),
```

যদি একটি রিকোয়েস্ট এর চেয়ে বেশি সময় নেয় তা "ধীম" বলে চিহ্নিত হয়।

**.env ফাইলে**:
```env
REQUEST_LOG_ANALYZER_SLOW_MS=500  # ৫০০ মিলিসেকেন্ড
```

### সর্বদা ধীম রিকোয়েস্ট ক্যাপচার করুন

নমুনা হার নির্বিশেষে সমস্ত ধীম রিকোয়েস্ট ক্যাপচার করুন:

```php
'always_capture_slow_ms' => env('REQUEST_LOG_ANALYZER_CAPTURE_SLOW_MS', 0),
```

উদাহরণ:
```php
'always_capture_slow_ms' => 1000,  // ১ সেকেন্ডের বেশি = সবসময় ক্যাপচার করুন
```

## 📊 সময় উইন্ডো ফিল্টার

### আজ

আজকের ডেটা (মধ্যরাত থেকে এখন পর্যন্ত):

```
/request-log-analyzer/analytics?period=today
```

### গত ২৪ ঘণ্টা

গত সম্পূর্ণ দিন:

```
/request-log-analyzer/analytics?period=24h
```

### গত সপ্তাহ

শেষ ৭ দিন:

```
/request-log-analyzer/analytics?period=7d
```

### গত মাস

শেষ ৩০ দিন:

```
/request-log-analyzer/analytics?period=30d
```

## 💡 অপ্টিমাইজেশন অন্তর্দৃষ্টি

### স্বয়ংক্রিয় সুপারিশ

অ্যানালিটিক্স পৃষ্ঠা স্বয়ংক্রিয়ভাবে সুপারিশ দেয়:

१. **"GET /api/products ধীম - অপ্টিমাইজ করুন"**
   - সমাধান: ইনডেক্স যোগ করুন, কেশিং যোগ করুন

२. **"/admin/users এ N+1 সমস্যা"**
   - সমাধান: Eager loading ব্যবহার করুন

३. **"৫% ত্রুটি হার - তদন্ত করুন"**
   - সমাধান: ত্রুটি ট্র্যাকার চেক করুন

## 📈 তুলনামূলক বিশ্লেষণ

### সময়ের সাথে তুলনা করুন

**গত সপ্তাহের সাথে এই সপ্তাহ**:

```
/request-log-analyzer/analytics?compare=prev
```

দেখবেন:
- পারফরম্যান্স উন্নত হয়েছে?
- ত্রুটি কমেছে?
- লোড বেড়েছে?

### শীর্ষ রুট তুলনা

দেখুন কোন রুটের পারফরম্যান্স খারাপ হয়েছে:

```
/request-log-analyzer/analytics?sort=slowest
```

## 🔐 ডেটা রিটেনশন

কতদিন ডেটা রাখবেন?

```php
'retention_days' => env('REQUEST_LOG_ANALYZER_RETENTION', 30),
```

৩০ দিনের পুরানো ডেটা স্বয়ংক্রিয়ভাবে মুছে যায়।
