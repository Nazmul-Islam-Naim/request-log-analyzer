## 🚀 দ্রুত শুরু করুন

### ইনস্টলেশন (१ কমান্ড)

```bash
php artisan analyzer:install
```

এটি স্বয়ংক্রিয়ভাবে:
- কনফিগ ফাইল তৈরি করে
- ডাটাবেস মাইগ্রেশন চালায়
- রিডি হয়ে যায়

### ড্যাশবোর্ড খুলুন

```
http://your-app.test/request-log-analyzer
```

## 🎯 বৈশিষ্ট্যগুলির সারাংশ

### १. HTTP রিকোয়েস্ট ট্র্যাকিং
প্রতিটি অনুরোধ ক্যাপচার করুন - মেথড, URI, সময়, ব্যবহারকারী

### २. ডাটাবেস কোয়েরি ট্র্যাকিং
প্রতিটি SQL কোয়েরি লগ করুন - সময়, প্যারামিটার, ফাইল/লাইন

### ३. ত্রুটি ট্র্যাকিং
সমস্ত ব্যতিক্রম ক্যাপচার করুন - বার্তা, স্ট্যাক ট্রেস, প্রসঙ্গ

### ४. পারফরম্যান্স অ্যানালিটিক্স
রুট দক্ষতা বিশ্লেষণ করুন - ধীম, জনপ্রিয়, গড় সময়

### ५. জিওআইপি ট্র্যাকিং
ব্যবহারকারীর অবস্থান সনাক্ত করুন - দেশ, শহর, স্থানাঙ্ক

### ६. লগইন ট্র্যাকিং
সমস্ত লগইন/লগআউট ইভেন্ট - সময়, আইপি, ডিভাইস

### ७. সক্রিয় ব্যবহারকারী
এখনই কে অনলাইন - রিয়েল-টাইম সংখ্যা, শেষ কার্যকলাপ

### ०८. সংবেদনশীল ডেটা লুকানো
পাসওয়ার্ড, টোকেন, কার্ড নম্বর স্বয়ংক্রিয়ভাবে মাস্ক করুন

### ०९. নমুনা এবং অ্যাসিঙ্ক
উচ্চ ট্রাফিকে পারফরম্যান্স বজায় রাখুন

### १०. ড্যাশবোর্ড এবং রিপোর্ট
সুন্দর UI এবং কার্যকর রিপোর্ট

## 🔑 মূল সেটিংস

### প্যাকেজ চালু/বন্ধ করুন

```env
REQUEST_LOG_ANALYZER_ENABLED=true
```

### প্রতিটি বৈশিষ্ট্য চালু/বন্ধ করুন

```env
REQUEST_LOG_ANALYZER_TRACK_QUERIES=true
REQUEST_LOG_ANALYZER_TRACK_ERRORS=true
REQUEST_LOG_ANALYZER_TRACK_GEO=true
REQUEST_LOG_ANALYZER_TRACK_LOGIN_HISTORY=true
```

### নমুনা হার (ট্রাফিক নিয়ন্ত্রণ)

```env
REQUEST_LOG_ANALYZER_SAMPLE_RATE=100     # সব লগ করুন (উন্নয়ন)
REQUEST_LOG_ANALYZER_SAMPLE_RATE=10      # ১০% লগ করুন (উৎপাদন)
```

### সতর্কতা

```env
REQUEST_LOG_ANALYZER_CAPTURE_ERRORS=true      # সব ত্রুটি লগ করুন
REQUEST_LOG_ANALYZER_CAPTURE_SLOW_MS=500      # ০.५ সেকেন্ডের উপরে সব
```

### অ্যাসিঙ্ক লগিং (পটভূমিতে)

```env
REQUEST_LOG_ANALYZER_ASYNC=true
REQUEST_LOG_ANALYZER_QUEUE_CONNECTION=redis
```

## 👤 অনুমতি এবং অ্যাক্সেস

### কে ড্যাশবোর্ড অ্যাক্সেস করতে পারে?

ডিফল্টে: `web` মিডলওয়্যার ব্যবহার করে (যে কেউ লগইন করা ব্যবহারকারী)

কাস্টমাইজ করুন:

```php
// config/request-log-analyzer.php
'middleware' => ['web', 'auth', 'admin'],  // শুধুমাত্র Admin
```

## 📞 সাহায্য এবং সমর্থন

### যদি কিছু বুঝতে না পারেন

१. প্রাসঙ্গিক ডকুমেন্টেশন পড়ুন
२. কনফিগ উদাহরণ দেখুন
३. ড্যাশবোর্ড অন্বেষণ করুন

### সাধারণ প্রশ্নগুলি

**Q: ড্যাশবোর্ড লোড হচ্ছে না**
A: মাইগ্রেশন চালান - `php artisan migrate`

**Q: ডাটা অনেক দ্রুত পূর্ণ হচ্ছে**
A: নমুনা হার কমান - `REQUEST_LOG_ANALYZER_SAMPLE_RATE=10`

**Q: আমি কিছু লুকাতে চাই**
A: `hidden_fields` কনফিগ পরিবর্তন করুন

**Q: অ্যাসিঙ্ক নিয়ে সমস্যা**
A: কিউ ওয়ার্কার চালান - `php artisan queue:work`
