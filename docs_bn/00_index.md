## প্যাকেজ পরিচয়

### এটি কি?

**Request Log Analyzer** একটি Laravel প্যাকেজ যা আপনার অ্যাপ্লিকেশনের প্রতিটি HTTP রিকোয়েস্ট স্বয়ংক্রিয়ভাবে ক্যাপচার এবং বিশ্লেষণ করে।

### এটি কি ক্যাপচার করে?

✅ **HTTP অনুরোধ** - মেথড, URL, স্ট্যাটাস কোড, সময়কাল  
✅ **ডাটাবেস কোয়েরি** - সমস্ত SQL কোয়েরি এবং তাদের কার্যকরতা  
✅ **ত্রুটি এবং ব্যতিক্রম** - অ্যাপ্লিকেশন ত্রুটি এবং স্ট্যাক ট্রেস  
✅ **জিওআইপি ডেটা** - ব্যবহারকারীর দেশ এবং শহর  
✅ **লগইন ইতিহাস** - ব্যবহারকারী লগইন/লগআউট ট্র্যাকিং  
✅ **সক্রিয় ব্যবহারকারী** - এখনই সাইটে কে আছে তা জানুন  
✅ **পারফরম্যান্স ডেটা** - রিস্পন্স টাইম বিশ্লেষণ  

### কেন এটি প্রয়োজন?

| সমস্যা | সমাধান |
|------|--------|
| অ্যাপ ধীর চলছে - কি কারণ? | **পারফরম্যান্স অ্যানালিটিক্স** ব্যবহার করুন |
| ব্যবহারকারী রিপোর্ট করছে ত্রুটি | **এরর ট্র্যাকিং** এবং **স্ট্যাক ট্রেস** দেখুন |
| ডাটাবেস ক্ষতিগ্রস্ত হচ্ছে | **কোয়েরি লগিং** দিয়ে সমস্যাজনক প্রশ্ন খুঁজুন |
| সন্দেহজনক আচরণ দেখছি | **আইপি ট্র্যাকিং** এবং **জিওআইপি** ডেটা দেখুন |
| কে কখন লগইন করছে তা জানতে চাই | **লগইন হিস্টরি** রিপোর্ট ব্যবহার করুন |

## ইনস্টলেশন

### প্রয়োজনীয়তা

- **PHP**: ৮.১ অথবা উচ্চতর
- **Laravel**: ১০.০, ১১.০, ১२.०, অথবা ১३.०
- **ডাটাবেস**: MySQL, PostgreSQL অথবা SQLite

### একটি কমান্ডে ইনস্টল করুন

```bash
php artisan analyzer:install
```

এই কমান্ডটি স্বয়ংক্রিয়ভাবে:
- কনফিগ ফাইল প্রকাশ করে
- সমস্ত ডাটাবেস মাইগ্রেশন চালায়

### ঐচ্ছিক ফ্ল্যাগ

```bash
php artisan analyzer:install --force       # বিদ্যমান কনফিগ অতিলিখিত করুন
php artisan analyzer:install --no-migrate  # মাইগ্রেশন এড়িয়ে যান
```

### ম্যানুয়াল ইনস্টলেশন

```bash
php artisan vendor:publish --tag=request-log-analyzer-config
php artisan migrate
```
