# २. ডাটাবেস কোয়েরি ট্র্যাকিং

## 🎯 এই বৈশিষ্ট্যটি কি?

এটি আপনার অ্যাপ্লিকেশন কর্তৃক সম্পাদিত প্রতিটি ডাটাবেস কোয়েরি স্বয়ংক্রিয়ভাবে লগ এবং বিশ্লেষণ করে।

## 🤔 কেন প্রয়োজন?

- কোন কোয়েরি সবচেয়ে ধীর তা খুঁজুন
- অপ্টিমাইজেশনের সুযোগ চিহ্নিত করুন
- N+1 কোয়েরি সমস্যা সনাক্ত করুন
- ডাটাবেস লোড কমান
- অ্যাপ পারফরম্যান্স উন্নত করুন

## 📝 কি তথ্য সংরক্ষিত হয়?

প্রতিটি কোয়েরির জন্য:

| ডেটা | বর্ণনা | উদাহরণ |
|------|-------|---------|
| **SQL** | সম্পূর্ণ কোয়েরি | SELECT * FROM users WHERE id = ? |
| **সময়কাল** | মিলিসেকেন্ড | ৪.५२ ms |
| **বাইন্ডিং** | কোয়েরি প্যারামিটার | [1] |
| **ফলাফল** | প্রভাবিত সারি | २ rows |
| **স্ট্যাক ট্রেস** | কোয়েরি কল করার স্থান | app/Models/User.php:45 |

## 🔧 কনফিগারেশন

### কোয়েরি ট্র্যাকিং চালু/বন্ধ করুন

```php
// config/request-log-analyzer.php
'track_queries' => env('REQUEST_LOG_ANALYZER_TRACK_QUERIES', true),
```

`.env` ফাইলে:

```env
REQUEST_LOG_ANALYZER_TRACK_QUERIES=true
```

### উপেক্ষা করার প্যাটার্ন

নির্দিষ্ট টেবিল থেকে কোয়েরি উপেক্ষা করুন:

```php
'ignored_query_tables' => [
    'rla_*',           // আমাদের নিজস্ব টেবিল উপেক্ষা করুন
    'cache',           // ক্যাশ টেবিল
    'sessions',        // সেশন টেবিল
],
```

### কোয়েরি সীমা

প্রতি রিকোয়েস্টে সর্বোচ্চ কোয়েরি সংখ্যা:

```php
'max_queries_per_request' => env('REQUEST_LOG_ANALYZER_MAX_QUERIES', 500),
```

বড় মূল্য = কম স্মৃতি, ছোট মূল্য = কম লগিং।

## 📊 কোয়েরি দেখুন

### রিকোয়েস্ট বিস্তারিতে

যেকোনো রিকোয়েস্ট খুলুন এবং "কোয়েরি" ট্যাব দেখুন:

```
/request-log-analyzer/requests/123
```

আপনি পাবেন:

✅ সমস্ত SQL কোয়েরি  
✅ প্রতিটি কোয়েরির সময়কাল  
✅ কোয়েরি প্যারামিটার (বাইন্ডিং)  
✅ কোথা থেকে কোয়েরি করা হয়েছে  

### ধীর কোয়েরি তালিকা

ড্যাশবোর্ডের প্রধান পৃষ্ঠায়:

```
/request-log-analyzer
```

"সবচেয়ে ধীর কোয়েরি" বিভাগ দেখুন।

## ⚡ পারফরম্যান্স অপ্টিমাইজেশন

### এন+१ সমস্যা সনাক্ত করুন

একটি রিকোয়েস্টে একই কোয়েরি বহুবার চলছে?

**সমস্যা**:
```php
$users = User::all();  // 1 কোয়েরি
foreach ($users as $user) {
    echo $user->posts->count();  // প্রতিটি ব্যবহারকারীর জন্য 1 কোয়েরি = N কোয়েরি
}
// মোট = 1 + N কোয়েরি
```

**সমাধান**:
```php
$users = User::with('posts')->get();  // 2 কোয়েরি
foreach ($users as $user) {
    echo $user->posts->count();  // কোনো নতুন কোয়েরি নেই
}
// মোট = 2 কোয়েরি
```

### ধীম কোয়েরি অপ্টিমাইজ করুন

ট্র্যাকারে একটি কোয়েরি ৫০০ms নিচ্ছে?

১. **ইনডেক্স যোগ করুন**:
```php
Schema::table('posts', function (Blueprint $table) {
    $table->index('user_id');
});
```

२. **SELECT নির্দিষ্ট কলাম**:
```php
User::select('id', 'name', 'email')->get();
```

३. **লিমিট ফলাফল**:
```php
User::limit(100)->get();
```

## 📈 বিশ্লেষণ এবং রিপোর্ট

### বৃহত্তম কোয়েরি

সবচেয়ে সময় নেওয়া কোয়েরিগুলি অ্যানালিটিক্সে দেখুন:

```
/request-log-analyzer/analytics
```

### কোয়েরি স্ট্যাটিস্টিক্স

- মোট কোয়েরি সংখ্যা
- গড় সময়কাল
- সর্বোচ্চ সময়কাল
- সবচেয়ে সাধারণ কোয়েরি

## 🔐 সংবেদনশীল তথ্য সুরক্ষা

কোয়েরি লগে যদি পাসওয়ার্ড বা টোকেন থাকে তা লুকিয়ে দিন:

```php
// config/request-log-analyzer.php
'scrub_patterns' => [
    '/password["\']?\s*[:=]\s*["\']?[^\s,&"\'>]+/i',
    '/Bearer\s+[\w\-\.]+/i',
    '/token["\']?\s*[:=]\s*["\']?[\w\-\.]{10,}/i',
],
```

এই প্যাটার্নগুলি কোয়েরিতে পাওয়া গেলে তা `***` দিয়ে প্রতিস্থাপিত হবে।

## 💾 ডাটাবেস টেবিল

সমস্ত কোয়েরি এখানে সংরক্ষিত হয়:

```
rla_queries
```

## ✅ সেরা অনুশীলন

১. **নিয়মিত পর্যবেক্ষণ করুন** - সপ্তাহে একবার ধীম কোয়েরি চেক করুন
२. **সতর্কতা সেট করুন** - ১০० ms এর বেশি কোয়েরির জন্য
३. **পরীক্ষা করুন** - উৎপাদনে পরিবর্তন করার আগে স্থানীয়ভাবে পরীক্ষা করুন
४. **ডকুমেন্ট করুন** - জটিল কোয়েরির জন্য মন্তব্য যোগ করুন
